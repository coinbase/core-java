# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-06-01

### Changed

- Moved the canonical repository to [coinbase/core-java](https://github.com/coinbase/core-java).
- Added GitHub Actions for format, lint, test, and Salus security scan.
- Added `.github/CODEOWNERS` for `@coinbase/core-java-write` and `@coinbase/core-java-admin`.

### Notes

- No intentional API breaking changes; minor bump signals repository migration.
- Equivalent to 1.1.1 on coinbase-samples aside from repository and tooling.

## [1.1.2] - 2026-06-01

### Changed

- Marked `coinbase-samples/core-java` as deprecated in the README.
- Documented migration to [coinbase/core-java](https://github.com/coinbase/core-java) and `coinbase-core-java` **1.2.0+** on Maven Central.

### Notes

- No intentional API changes.

## [1.1.1] - 2026-06-01

### Notes

- Prior release published to Maven Central as `com.coinbase.core:coinbase-core-java:1.1.1`.
